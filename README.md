# Browser AI Games

Free browser games made with AI — racing, fighting and adventure. No download, no build step: every game is a single HTML file.

**▶ Play:** https://ozzoet.github.io/-browser-ai-games/

| Game | Genre | Players | Path |
|---|---|---|---|
| Afterglow GP | 3D city circuit racing, split-screen | 1–2 | [`city-drive/`](city-drive/) |
| Dino Frenzy | Arcade dinosaur race | 1–2 | [`dino-frenzy/`](dino-frenzy/) |
| Fight! | 3D fighting game | 1–2 | [`fight/`](fight/) |
| Studio Zero | 3D action adventure | 1 | [`studio-zero/`](studio-zero/) |
| City Rush | Sprint racing | 1 | [`city-rush/`](city-rush/) |

All games are in English.

## Run locally
Open `index.html` in a browser, or serve the folder: `python -m http.server 8000` → http://localhost:8000

## Deploy (GitHub Pages)
Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
